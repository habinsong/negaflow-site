Development engine

Chroma Engine

Chroma Engine is the film inversion and development engine in the Chromabase module.

FILM BASE Automatic / Manual

The film base is measured automatically with no setup, and the negative is inverted to a positive. For manual control, select an unexposed area with the eyedropper or enter RGB values directly.

Defect restoration

GrainMend

GrainMend RGB is an independently developed software method that detects and restores dust, pinholes, scratches, and emulsion damage without an infrared channel.

GrainMend RGB

GrainMend RGB Defect Restoration

Guided and Brush: about 1 second · Auto: 5–10 seconds Compared with the 30–90 seconds typically required for a hardware IR pass, GrainMend RGB is about 3–90× faster.

Auto

Finds and restores defects across the photograph.

Guided

Finds defects inside an area you specify.

Brush

Paints the area to restore directly.

Clone Stamp

Copies pixels from a selected source to another location.

Detection that rivals hardware IR

GrainMend RGB detects defects directly in the RGB image and checks nearby texture, direction, and structure before restoring them. Lines and grids in the photograph are kept separate from scratches.

Review and correct it yourself

You can inspect the detection mask and restored result, then correct the affected area yourself.

Non-destructive layers

Each GrainMend RGB layer can be adjusted in strength, inspected as a mask, disabled, or deleted separately.

False-detection warning

GrainMend alerts the user when false-detected areas are likely to occur.

GrainMend IR

GrainMend IR is an optional path when the scanner plugin provides an infrared channel. Its detection result is added to the same edit history as GrainMend RGB.

GrainMend RGB is an independently developed software method, separate from hardware infrared cleaning. GrainMend IR uses the scanner’s infrared channel; it is not an implementation or compatibility mode of Digital ICE, iSRD, or SRDx.

Color Mathematics

32-bit Float Linear Pipeline

Inversion and tone are computed in 32-bit float linear space prior to gamma encoding, minimising clipping and tone degradation.

Dmin Density Inversion

Density D = log₁₀(Dmin/T) is calculated from linear transmittance and unexposed base measurements.

Stretched Exponential Curve

Applies a dedicated print response curve with an exact inverse function derived from four reference points.

Decoupled Processing

Film emulsion properties, scan light source, and scanner target looks are evaluated in separate stages.

Output Color Space Management

Converts to sRGB, Display P3, Adobe RGB, or custom RGB Printer ICC profiles at the final display and export stages.

48-bit RGB (16-bit per Channel) Precision

Supports full 48-bit RGB (16-bit R/G/B, 281 Trillion Colors) input and output, preventing posterization and banding during extreme tonal adjustments.

Lossless Archival Output

Pairs 48-bit I/O with 32-bit float linear processing, guaranteeing maximum archival quality for high-resolution print production.

Film profiles

Film Stock Calibration Dataset

928 Recorded image observations
15 Bundled scanner profiles

The bundle contains 15 scanner profiles made from film material I photographed myself. The profiles record 928 image observations, and every profile is currently marked realOnly.

realOnly identifies a profile built from real scans and still under active development and refinement. More scan material from a wider range of films and equipment will be added, and the profiles will continue to expand and improve with it.

Profiles are never applied from the scanner name alone; the user selects one explicitly. SHA-256 hashes are provided for both the files and the list.

928 is the sum of the observations in each profile, not 928 distinct photographs. The same film can be counted for more than one scanner. The scans were reviewed directly, files with false detections were excluded, and the profiles were built from those measurements.

Basic workflow

  1. Import image files or scan with an installed plugin.
  2. Choose the film type and measure the film base.
  3. Adjust colour and tone in Chroma Engine.
  4. Apply GrainMend to photographs that need it.
  5. Check the result with Compare and the histogram, then print or export.
  6. Shortcuts, folder paths, presets, and adjustments can all be customised.

FAQ

Frequently Asked Questions

How do I open the app if macOS shows a developer warning?

Current GitHub release files are ad-hoc signed. If macOS blocks the first launch, navigate to System Settings → Privacy & Security and choose Open Anyway.

Can I connect a physical scanner (e.g. Epson) directly?

Physical scanner connection requires the separate open-source negaflow-scanner-sane plugin. Without the plugin, you can immediately develop camera copy files or existing scans (TIFF, JPEG, RAW).

Does negaflow support camera RAW files and 16-bit TIFF?

Yes, it supports all camera RAW formats handled by macOS Image I/O, as well as 8-bit/16-bit TIFF, JPEG, and PNG files.

Are original image files modified during editing?

No. negaflow is 100% non-destructive. Original files and third-party sidecars are never modified; all edits are stored in an independent SQLite catalog.

Does negaflow support both Apple Silicon and Intel Macs?

Yes, negaflow is distributed as a Universal PKG for both Apple Silicon (M1/M2/M3/M4) and Intel Macs, requiring macOS 14.0 or later.

Can I use negaflow alongside Photoshop or Lightroom?

Yes. You can export 16-bit TIFF or JPEG files with preserved EXIF metadata and seamlessly pass them to Lightroom, Photoshop, or Capture One.

Do I need the scanner plugin for digital camera scans?

No. The plugin is only required for controlling physical flatbed or film scanners. Digital camera copies (RAW/TIFF) can be developed out of the box.

Is negaflow a subscription or open-source software?

negaflow is open-source software under the Apache License 2.0. It is completely free to download and use with no monthly subscription fees.

How does negaflow handle large libraries with hundreds of frames?

negaflow uses an SQLite database with WAL mode and automatic frame cache relief, ensuring stable, fluid performance across thousands of photos.

Can I save custom development presets or copy settings across rolls?

Yes. You can save custom presets or use Settings Paste Scope to selectively copy exposure, tone, or dust restoration adjustments to entire 36-exposure rolls.
